# Constraints

Place the exact Xilinx Design Constraints (`.xdc`) file used by the original Vivado implementation here.

The design was described as targeting a 10 ns clock period (100 MHz), but the original clock port name and exact constraints must come from the real project. Do not use a guessed XDC to substantiate published results. If you create new constraints, rerun implementation and keep those reports with the same revision.
